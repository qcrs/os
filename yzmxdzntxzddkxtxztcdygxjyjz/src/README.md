# 多智能体协作系统 - 低开销通信与共享记忆机制

本项目为第三届中国研究生操作系统开源创新大赛参赛作品，致力于设计并实现一套创新的多Agent协作系统原型。

## 核心创新点

### 1. **低开销通信机制**
- 设计结构化通信协议，替代冗长自然语言交互
- 通过高密度语义单元传递（动作、参数、结果、能力）
- 相比纯文本协作节省通信成本和token消耗

### 2. **非文本状态传递**
- 实现Embedding和语义向量的直接交换
- 支持隐藏状态特征在Agent间传递
- 减少文本编解码开销，提高协作效率

### 3. **共享记忆机制**
- 将任务中间结果沉淀为可复用的记忆单元
- 支持按语义相似度检索历史记忆
- 实现跨任务知识积累与协同增强

## 快速开始

### 环境要求
- Python 3.8+
- Linux/macOS (或 WSL on Windows)
- 可选：Docker

### 安装

```bash
# 克隆或进入项目目录
cd multi-agent-collab

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/macOS
# 或
venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 运行演示

```bash
# 运行示例任务 1
python examples/example_task1.py

# 运行性能对比
python examples/benchmark.py

# 查看评测结果
python examples/comparator.py
```

## 核心模块说明

### 1. 结构化通信协议 (Protocol)
定义了Agent间的消息格式：
- 握手消息 (Handshake)
- 能力描述 (Capability)
- 动作请求 (Action Request)
- 结果响应 (Result Response)

### 2. 非文本状态交换 (State Exchange)
支持三种状态传递方式：
- Embedding向量传递
- 隐藏状态特征共享
- 中间表示直接交换

### 3. 共享记忆机制 (Shared Memory)
记忆单元包含：
- ID、来源Agent、创建时间
- 任务主题、摘要描述
- 语义向量索引

### 4. 评测模块 (Evaluation)
测量关键指标：
- 通信Token/字符开销
- Agent消息次数
- 任务总耗时
- 记忆命中率
- 性能提升比例

## 实验设计

### 任务集合
1. **RAG任务** (Task 1): 多步检索+总结
2. **代码分析任务** (Task 2): 规划+执行+生成

### 对比模式
- **纯文本模式**: 传统自然语言交互
- **结构化模式**: 新型协议 + 向量状态 + 共享记忆

### 评估维度
- 通信效率 (25分)
- 状态传递创新 (20分)
- 记忆复用效果 (20分)
- 系统完整性 (20分)
- 实验验证 (15分)
