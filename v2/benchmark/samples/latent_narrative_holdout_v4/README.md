# Latent Narrative Holdout v4

V4 is the active preregistered narrative suite. It keeps the case-scoped
evidence authorization, long-document analysis, cross-document synthesis, and
conditional operating-plan selection introduced in v2. The v2 and v3
preflight artifacts remain immutable failure records.

Tasks enumerate analytical dimensions so a model cannot replace a requested
qualifier with a different but valid management action. This is a task contract,
not an answer key: no expected fact, score term, selected branch, or answer
summary is visible to the model.

The plan cases remain document-grounded branch selection and must not be cited
as Runtime Controller replan evidence.
